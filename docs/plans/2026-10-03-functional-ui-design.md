# Functional Game UI Design

The interface should read like a purpose-built game display. It keeps the existing typefaces and the charcoal, ivory, and muted-gold palette while removing visual habits that feel generated or ornamental: glass blur, gradients, glow, repeated card outlines, tiny uppercase marketing labels, excessive tracking, and decorative copy.

The game viewport remains the main surface. Health and player count use one compact line. The map uses a flat dark backing and a simple street label. Speed remains large because it is meaningful during play. The side statistics sit in one open column separated by spacing and thin rules rather than individual cards.

Labels use sentence case and familiar words: Players, Health, Energy, Top speed, Distance, Bolts, and Braking. The start state shows the game name and a Play button. The page footer contains only credits.
